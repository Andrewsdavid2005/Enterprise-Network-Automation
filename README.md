# Enterprise Network Automation Lab

## Overview

A Python-based network automation project designed to automate
Cisco network monitoring, configuration backup, and health reporting.

## Technologies

- Python 3.12
- Netmiko
- Paramiko
- Cisco IOS
- Cisco Packet Tracer
- OSPF
- SSH
- Git & GitHub
